# 校园集市 · 代码审查与修复记录

> 本记录用于课程报告的「测试与质量保证」章节，说明独立审查发现了什么、修复了什么、哪些被明确延后。审查在本地工作树完成，项目未初始化 git，因此没有提交哈希。

## 1. 审查方式

- 独立子代理（Opus）通读 `app/`、`templates/`、`static/`、`tests/`、`schema.sql`、`seed.py`、`config.py`、`run.py`、`docs/`。
- 逐项检查实现计划的 Review Focus：暂停 / 下架 / 删除商品的直达权限、上传校验、越权 POST 与 CSRF、英文校验、搜索与分页口径。
- 实际运行 `python -m pytest -q`，并手工探测路由、重定向、上传与权限矩阵。
- 审查结果：1 个 Critical、4 个 Important、若干 Minor。

## 2. Critical：开放重定向绕过（已修复）

**问题**：`safe_next_url` 只检查 `//` 和反斜杠。百分号编码的制表符（`%09`）或换行（`%0a`）可绕过，`/lang/en?next=/%09/evil.example` 会返回指向 `//evil.example` 的 302；换行还可能导致 500。

**修复**：

- 统一在 `safe_next_url` 中拒绝控制字符、反斜杠、编码控制字符、解码后以 `//` 开头的路径，并用 `urlsplit` 要求无 scheme / netloc。
- `main.set_language` 改用同一个 helper，不再复制判断。
- 新增回归测试：`test_safe_next_url_blocks_control_characters`、`test_language_switch_blocks_encoded_redirect`、`test_login_blocks_encoded_control_redirect`。

## 3. Important（已修复）

### 3.1 停用分类编辑会静默改分类

**问题**：编辑页只加载启用分类，当前分类被停用时，浏览器会默认提交第一个启用分类，商品被悄悄改类。

**修复**：

- 编辑页允许保留当前分类，即使它已停用；新增「请选择分类」空选项，避免浏览器隐式选择。
- 校验允许 `category_id == 当前分类`，但新选择仍必须是启用分类。
- 回归测试：`test_edit_keeps_disabled_current_category`。

### 3.2 Review Focus 测试缺口

补了以下测试：

- 暂停商品对非发布者只读、无联系方式、无编辑 / 状态 / 删除 / 收藏 / 举报控件。
- 管理员下架、卖家删除的只读视图无操作控件。
- 非发布者 POST 编辑返回 403。
- 商品状态 POST 缺失 CSRF 返回 400。
- 通过 `/publish` 路由提交伪造图片被拒绝（不只在单元层测 `validate_image`）。
- 中文关键词搜索。
- 停用分类编辑、英文地点建议、超大分类 ID、超大商品 ID。
- 控制字符重定向与语言切换重定向。

### 3.3 调试模式与默认密钥

**问题**：`run.py` 无条件 `debug=True`，未处理异常会暴露 Werkzeug 调试器；`SECRET_KEY` 有公开默认值。

**修复**：

- `Config.DEBUG` 由 `FLASK_DEBUG` 控制，默认 `0`；`run.py` 使用该配置。
- 未设置 `SECRET_KEY` 时在启动日志中明确警告。
- README 增加开发 / 部署说明。
- 回归测试：`test_debug_defaults_off`。

### 3.4 英文界面地点建议仍是中文

**问题**：`<datalist>` 的地点值硬编码为「宿舍楼下 / 一食堂 / …」。

**修复**：

- 新增 `items.location.*` 中英文键，发布 / 编辑页按当前语言渲染建议。
- 回归测试：`test_publish_location_suggestions_are_translated`。

## 4. 按规格对齐的调整

- **联系方式可见性**：对买家仍在售才显示；卖家本人与管理员不受状态限制（已售 / 暂停 / 下架也可见），与设计文档 §7.10 一致。相关测试同步更新。
- **英文后台截图**：补充 `docs/screenshots/admin-en.png`。
- **确认弹窗**：状态更新、管理员下架、举报下架也加 `data-confirm`。
- **上传交互**：支持拖拽、预览、逐张移除。
- **后台统计**：下架 / 卖家删除以「管理员下架数 / 卖家删除数」分别显示。
- **可访问性**：后台分类表单补充 `for` / `id`；导航、分页、轮播的 ARIA 标签走 `t()`；轮播圆点改为 `aria-pressed`。
- **文案与文档**：修正「快捷改价」、联系方式说明、测试数量（85）、密码哈希算法（Werkzeug 默认 scrypt）、演示价格范围等。

## 5. 明确延后的 Minor

1. **发布 / 编辑多行写入未包在单个事务内**：中途失败可能留下部分图片行。当前用异常清理文件，未做 `BEGIN/COMMIT/ROLLBACK`。
2. **管理员可停用最后一个启用分类**：发布下拉可能为空；需要管理员手动重新启用。
3. **举报下架原因带 `reported:` 英文前缀**：中文后台显示混合文本；不影响功能。
4. **自定义 413 / 405 页面缺失**：超大请求体或错误方法使用 Flask 默认页。
5. **正式无障碍审计与跨浏览器矩阵未做**：只做了 1440 / 375 与 Edge 实测，未做屏幕阅读器测试。
6. **后台统计仍是一张卡显示两个数字**，而非两张独立卡；信息已分别列出。

- 推荐算法、图片 CDN / 对象存储、通知系统。
- 管理员封禁账号、批量审核、排序表格。
- 高并发 / 压测 / 多进程 SQLite、限流、MFA、TLS / 安全头、备份恢复。
- 真实用户可用性研究与满意度调查。

## 7. 分享模式

新增 `share.py` + `分享给别人.bat` + 桌面「校园集市」公网分享快捷方式：

- 使用 Waitress 在本机 127.0.0.1:5000 提供 WSGI 服务。
- 通过 Cloudflare 临时隧道生成 `https://*.trycloudflare.com` 公网链接，手机 / 电脑浏览器直接打开。
- 每次分享生成随机管理员密码，通过 `CAMPUS_SHARE_ADMIN_HASH` 仅对本次进程生效；原数据库管理员密码不被修改，分享结束后恢复。
- 新增 `test_share_admin_password_override`：分享期间原管理员密码失败、分享密码成功。
- 链接为临时链接；关闭分享窗口即失效。永久在线需要云平台部署。

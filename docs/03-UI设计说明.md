# 校园集市 · UI 设计说明

## 1. 设计方向

关键词：**清晨校园公告栏**。

不是通用电商模板，也不是厚重后台。网站以浅蓝和白色为底，商品像一张张贴在公告栏上的卡片；圆角、轻阴影、清晰的层级和状态色，让「在售 / 已售 / 暂停」一眼可辨。

设计原则：

1. **状态优先**：状态标签、灰化、提示条贯穿卡片、详情、我的发布和后台。
2. **轻量**：无外部字体、无图标库、无前端框架；CSS 变量 + 内联 SVG 图标。
3. **可读**：中文优先，行高 1.7，正文与背景对比充足；英文切换后布局不塌。
4. **克制**：主色只用于行动和选中；价格用暖橙，状态用绿 / 灰 / 琥珀。
5. **可演示**：断网、无 CDN、无 npm，本地打开即可完整展示。

## 3. 字号与节奏

| 层级 | 字号 | 用途 |
|---|---|---|
| 页面大标题 | `clamp(1.8rem, 3.4vw, 2.5rem)` | 列表页、后台页 |
| 首页主标题 | `clamp(2.2rem, 4.4vw, 3.5rem)` | Hero |
| 区块标题 | `clamp(1.35rem, 2.4vw, 1.75rem)` | 首页各分区 |
| 卡片标题 | `0.95–1rem` | 商品名 |
| 正文 | `0.9–1rem` | 描述、表单 |
| 元信息 | `0.72–0.84rem` | 日期、浏览量、标签 |

- 行高 1.7；标题 1.25。
- 数字使用 `font-variant-numeric: tabular-nums`，价格、浏览量对齐。
- 间距以 4px 为基准：8 / 12 / 16 / 20 / 24 / 32 / 48。
- 页面最大宽度 1180px，移动端左右留白 14–20px。

## 4. 组件规范

### 4.1 导航

- 白色半透明 + 背景模糊，底部 1px 边线，吸顶。
- 左侧 logo（循环箭头图标）+ 品牌名。
- 中间主导航：首页、全部商品、分类浏览；登录后追加发布、我的发布、个人中心；管理员追加后台。
- 右侧：语言切换、登录 / 注册，或用户名 + 退出。
- 移动端（≤760px）：导航收进汉堡菜单；语言切换移到菜单底部，避免顶部拥挤。
- 当前页用浅蓝底 + 深蓝字标记。

### 4.2 按钮

- 主按钮：蓝色渐变、白色文字、柔和阴影；悬停上浮 1px。
- 次按钮：白底、浅蓝边框。
- 危险按钮：白底、红字、红边框；删除 / 下架必须二次确认。
- 小按钮高度 38px；标准按钮 46px；触控目标不小于 42px。
- 所有按钮有 `:focus-visible` 焦点环。

### 4.3 状态标签

```text
● 在售    绿色底 / 绿色文字
● 已售    灰色底 / 灰色文字
● 暂停出售 琥珀底 / 琥珀文字
```

标签同时使用颜色和文字，不依赖单一颜色传达含义。卡片、详情、我的发布、后台表格共用同一套类名：

```css
.status-chip--on_sale
.status-chip--sold
.status-chip--unavailable
```

### 4.4 商品卡片

- 4:3 图片区，左上角状态标签。
- 标题两行截断；价格橙色加粗，原价删除线。
- 元信息：分类 · 成色，发布日期 · 浏览量。
- 已售整卡降低饱和度，并叠加浅色蒙层。
- 悬停上浮 4px、阴影加深；不使用夸张缩放。

### 4.5 首页

- Hero：左侧大标题 + 说明 + 双行动按钮 + 平台统计；右侧倾斜 1.1° 的「状态一目了然」公告卡，顶部有黄色图钉。
- 标题使用浅蓝马克笔式下划线（`linear-gradient` + `box-decoration-break`）。
- 轮播：3 张文字卡，6 秒自动切换，悬停 / 聚焦暂停，圆点可点，支持左右方向键。
- 分类：4 列卡片，图标底色按分类区分；平板 3 列、手机 2/1 列。
- 最新发布 / 最热浏览：8 件商品，4/3/2/1 列响应式网格。

### 4.6 表单

- 标签在上，必填星号红色；错误文案贴字段下方。
- 输入框 46px 高、12px 圆角、聚焦时蓝色描边 + 4px 光晕。
- 发布 / 编辑页：左侧主表单，右侧粘性提交卡；移动端单列。
- 图片上传：虚线拖拽区 + 本地预览 + 逐张移除；编辑时显示已有图片和移除复选框。
- 状态切换：下拉 + 「更新状态」按钮，放在详情页和我的发布中。

### 4.7 详情页

- 两列：左侧图集（主图 + 缩略图），右侧信息卡（状态、标题、价格、元信息、描述、卖家、联系方式、操作）。
- 桌面端信息卡粘性（`top: 92px`）；移动端单列。
- 已售 / 暂停 / 下架 / 删除使用不同颜色的提示条。
- 联系方式对买家仅在「在售 + 已登录」时展示；卖家本人与管理员不受状态限制。

### 4.8 我的发布 / 收藏 / 历史

- 我的发布：状态筛选标签 + 横向管理行（缩略图、标题、状态、价格、日期、浏览量、操作）。
- 管理员下架的商品显示原因并禁用操作；卖家已删除的商品不出现。
- 收藏：4 列卡片；已售 / 失效卡片降饱和，取消收藏按钮始终可用。
- 历史：仅显示可公开访问的商品，复用商品卡片。

### 4.9 后台

- 左侧 220px 粘性导航（概览 / 商品 / 分类 / 举报），右侧内容。
- 统计卡 4 列；分类分布用横向条形图（纯 CSS）。
- 表格在小屏横向滚动；筛选栏与前台一致。
- 移动端导航变为横向滚动条。

### 4.10 反馈与空状态

- Flash：成功绿、错误红、信息蓝，固定在导航下方；成功 / 信息 6 秒自动消失，可手动关闭。
- 空状态：虚线边框 + 说明 + 行动按钮。
- 错误页：超大浅色状态码 + 标题 + 说明 + 返回首页。
- 删除 / 下架 / 标记已售使用原生 `confirm`，避免额外依赖。

## 5. 响应式断点

| 断点 | 行为 |
|---|---|
| ≥1120px | 完整导航；商品 4 列；分类 4 列；后台侧栏 |
| 980–1119px | 导航间距收紧；商品 4 列；详情单列；认证页隐藏装饰侧栏 |
| 760–979px | 商品 3 列；分类 3 列；后台统计 3 列；导航仍为桌面 |
| 521–759px | 商品 2 列；分类 2 列；导航变汉堡菜单；语言切换进菜单 |
| ≤520px | 商品 1 列；分类 1 列；表单单行；筛选栏堆叠；后台统计 2 列 |

实测 375px 下 `document.documentElement.scrollWidth = 375`，无横向溢出。

## 6. 无障碍

- 顶部「跳到主要内容」链接，键盘聚焦时出现。
- 所有图片有 `alt`；装饰性 SVG 使用 `aria-hidden="true"`。
- 表单控件均有关联 `label`；错误文案紧邻字段。
- 状态同时使用颜色和文字。
- 可见的 `:focus-visible` 焦点环。
- Flash 容器 `aria-live="polite"`。
- 轮播支持键盘左右键；悬停 / 聚焦暂停自动播放。
- `prefers-reduced-motion` 下关闭动画与自动轮播。
- 主要文字 / 背景对比度满足 WCAG AA；价格、状态色均加深处理。

## 7. 双语设计

- 中文默认，英文通过 `/lang/en` 切换并写入会话。
- 系统文案（导航、表单、校验、状态、后台、错误页）全部走 `t()`。
- 分类名、成色、状态、地点建议均有中英文映射。
- 用户发布的标题、描述、举报原因保持原文，不自动翻译。
- 英文长度变化通过：
  - 导航间距收紧；
  - 标题 `text-wrap: balance`；
  - 表格横向滚动；
  - 按钮使用 `flex` 自适应宽度。
- 日期格式：中文 `2026年11月1日`，英文 `1 Nov 2026`。

## 9. 已知取舍

1. 不使用外部字体与图标库：保证离线，但字体依赖系统；Windows 上以微软雅黑为主。
2. 商品图使用本地 SVG 占位图：演示统一、无版权风险；上传真实图片后自动替换。
3. 删除 / 下架使用原生确认框：功能明确，视觉朴素；课程演示足够。
4. 后台表格未做列排序 / 批量操作：以审核与举报为主路径，保持实现可讲解。
5. 详情页图片切换为前端直接替换 `src`：无复杂灯箱，减少依赖。

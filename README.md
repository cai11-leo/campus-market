# 校园集市 Campus Market

一个面向本校学生的二手闲置交易网站。学生可以发布、分类、标价、收藏和浏览闲置，并随时把商品状态切换为「在售 / 已售 / 暂停出售」；管理员可以在后台审核商品、管理分类和处理举报。

A campus-only second-hand marketplace for students. Post, classify, price, save, and browse idle items, with a live status of on sale / sold / paused. Admins can review listings, manage categories, and handle reports from a dedicated dashboard.

> 课程项目演示版：数据、账号、图片全部本地生成，不依赖校外服务、CDN 或在线字体。  
> Coursework demo: all data, accounts, and images are local. No external services, CDNs, or web fonts.

---

## 功能 Features

- 学生注册 / 登录 / 退出，密码哈希与会话管理
- 发布闲置：1–5 张图片、分类、售价、描述、成色、交易地点
- 7 个校园高频分类：教材书籍、电子数码、生活用品、运动健身、美妆衣物、文具文创、其他闲置
- 商品状态：在售、已售、暂停出售；发布者可随时切换
- 已售商品灰化、保留记录、隐藏联系方式；暂停商品从公开列表下架
- 搜索、分类筛选、状态筛选、价格 / 最新 / 浏览量排序、分页
- 收藏、浏览记录、个人资料与密码修改
- 举报商品；管理员下架 / 恢复、分类增改启停、举报处理
- 中英文双语切换，覆盖导航、表单、校验、状态、后台、错误页
- 管理后台统计：用户、商品、状态、浏览量、待处理举报、分类分布
- 软删除：区分「管理员下架」与「卖家删除」，仅前者可恢复
- 85 个 pytest 自动化测试 + 桌面 / 移动端视觉检查

## 快速开始 Quick Start

要求：Python 3.10+（本项目在 Python 3.13.12 上测试通过）。

```bash
cd campus-market
python -m venv .venv
```

Windows：

```bash
.venv\Scripts\activate
```

macOS / Linux：

```bash
source .venv/bin/activate
```

安装依赖并初始化演示数据：

```bash
pip install -r requirements.txt
python seed.py --reset
python run.py
```

打开 <http://127.0.0.1:5000>。

> 默认关闭 Flask 调试模式，未处理的异常会显示自定义 500 页面。开发时如需热重载：
> Windows PowerShell：`$env:FLASK_DEBUG=1; python run.py`；macOS / Linux：`FLASK_DEBUG=1 python run.py`。
> 不要把调试模式或默认 `SECRET_KEY` 用于任何对外部署。

> `python seed.py --reset` 会删除 `instance/campus_market.db` 与 `static/uploads/` 中的上传文件，然后重新生成 28 件演示商品、7 个分类、4 个账号和 14 张 SVG 占位图。  
> `seed.py --reset` is destructive: it recreates the demo database and clears uploaded files.

### 桌面快捷方式 Desktop Shortcuts

Windows 下本地运行可双击项目根目录的 `启动校园集市.bat`，它只在本机启动 Flask 并打开 `http://127.0.0.1:5000`。

桌面上已生成两个快捷方式：

| 快捷方式 | 作用 |
|---|---|
| `校园集市` | 启动公网分享并自动打开手机可访问的链接；热键 `Ctrl + Alt + C` |
| `校园集市-项目文件夹` | 打开项目目录 |

> 桌面「校园集市」现在指向公网分享，不是本地模式。纯本地演示请双击 `启动校园集市.bat`。

如果移动了项目文件夹，或热键与其它软件冲突，可重新运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\create_desktop_shortcuts.ps1
```

热键可在快捷方式「属性 → 快捷键」中修改或清空。

### 分享给别人（手机 / 电脑浏览器）

这是一个 Flask + SQLite 动态网站，**接收者不需要安装 Python**；他们只需要一个网址。网址背后需要一台机器运行服务：

```text
你的电脑（运行 Flask + 隧道）
        │
        ▼
https://xxxx.trycloudflare.com  ← 发给同学，手机/电脑浏览器直接打开
```

使用方式：

1. 双击桌面 **校园集市**（或项目里的 `分享给别人.bat`）。
2. 等待终端打印 `https://....trycloudflare.com`；脚本会自动用默认浏览器打开该链接。
3. 把浏览器地址栏里的链接发给同学；手机和电脑都能直接打开。
4. 终端会同时打印本次分享的 **管理员密码**。分享期间原 `Admin@12345` 不生效，关闭分享窗口后恢复。
5. 分享窗口必须保持打开，电脑不能关机/休眠（脚本会阻止系统休眠）；关闭窗口或按 Ctrl+C 后链接立即失效。

首次分享会自动下载 Cloudflare 客户端（约 55 MB，保存到 `%LOCALAPPDATA%\CampusMarket\`）。如果 GitHub 下载失败，可先用 `winget install Cloudflare.cloudflared` 或手动放置 `cloudflared.exe`，再设置 `CLOUDFLARED` 环境变量。

> 安全提示：任何拿到链接的人都可以注册、浏览和发布；学生演示账号 `2023001/2023002/2023003` 密码 `Demo@12345` 是公开的。管理员只接受本次终端打印的随机密码，不要把该密码公开转发。
>
> 如果手机打不开 `trycloudflare.com`（少数网络环境会拦截），可以让手机和电脑连同一 Wi-Fi，改用局域网地址；或部署到 Render/Railway 获得永久链接（需要云平台账号）。

> A dynamic Flask site cannot be opened as a single local file on a phone. Share the public URL generated by `share.py`; recipients only need a browser. The link lives while the sharing window and your computer are running.

## 数据与图片 Data and Images

- 数据库默认位置：`instance/campus_market.db`（可通过环境变量 `DATABASE` 覆盖）。
- 上传图片保存在 `static/uploads/`，文件名使用 UUID，避免路径穿越和重名。
- 单张图片上限 5 MB，最多 5 张，支持 jpg / jpeg / png / webp；服务端同时校验扩展名与文件头。
- 演示商品使用 `static/img/placeholders/` 下的本地 SVG，断网也能完整展示。

## 常见问题 Troubleshooting

**端口 5000 被占用**  
修改 `run.py` 中的端口，或结束占用进程后重启。

**Windows 终端中文乱码**  
在 PowerShell 中执行 `chcp 65001`，或使用 Windows Terminal；项目文件本身均为 UTF-8。

**想清空演示数据重新开始**  
停止服务后运行 `python seed.py --reset`。

**上传图片失败**  
确认格式为 jpg / jpeg / png / webp、单张不超过 5 MB、总数 1–5 张；发布前需在个人中心填写微信或手机号。

**页面样式没有更新**  
浏览器强制刷新（Ctrl+F5）或清除缓存。
